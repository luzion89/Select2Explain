# Select2Explain 用户指南

## 适用平台

当前这份指南主要面向 Windows。macOS 已补齐代码路径与文档，但尚未在本轮环境中做实际编译和运行测试，因此仍建议按“待验证平台”看待。

## 应用做什么

Select2Explain 会在后台常驻系统托盘。你在其他应用里用鼠标选中一段文字后，它会自动抓取当前选区和必要上下文，用 AI 生成解释，并把结果显示在鼠标右上方的小浮窗里。

## 首次配置

### 1. 打开控制面板

启动应用后会出现主控制面板。如果之后关闭了主窗口，也可以从系统托盘菜单重新打开。

### 2. 配置 Provider

控制面板中需要确认这三个字段：

- Base URL：默认 `https://openrouter.ai/api/v1`
- 文本模型：默认 `qwen/qwen2.5-vl-72b-instruct`
- 视觉模型：默认 `qwen/qwen2.5-vl-72b-instruct`

改完后点击“保存设置”。

### 3. 保存 API Key

在 API Key 区域输入你的 key，点击“保存 Key”。

Key 会保存到系统安全存储，不会写入普通文本配置文件。

### 4. 测试连接

点击“测试连接”，确认当前配置可用。成功时会显示延迟，失败时会显示 Provider 或网络错误。

### 5. 开启自动监听

打开“自动监听”开关后，后台选区监听会立即生效，开关状态会自动写回本地设置文件。

如果你要排查问题，也可以同时打开“本地调试日志”开关，程序会把监听到的选区、截图是否成功、窗口全文摘要截断和 AI 分支决策写入本地日志文件。

## 日常使用

1. 开启自动监听并保存设置。
2. 关闭主窗口或让它留在后台，程序仍会驻留托盘。
3. 在浏览器、编辑器、文档工具等应用里用鼠标选中文字。
4. 稍等片刻，解释 popup 会出现在鼠标右上方。
5. 点击任意其他位置，popup 自动隐藏。

## 调试入口

控制面板中有两个调试按钮：

- 测试选区探测：验证当前是否能读到选区。
- 测试完整采集：验证窗口文本和截图是否能被采到。

另外还可以开启“本地调试日志”，日志文件路径会直接显示在控制面板中。

如果自动解释没有触发，先用这两个按钮排查是“选区没拿到”还是“完整上下文没拿到”。

## 常见问题

### 选中文字后没有反应

- 确认已经打开“自动监听”。
- 确认 API Key 已配置。
- 某些应用的 UI Automation 暴露较弱，可能当前窗口能识别，但选区文本本身读不到。
- 先用“测试选区探测”检查当前前台应用是否能被读到。
- 如果仍然没有结果，打开“本地调试日志”，查看日志里是否出现 `probe found no accessible selection` 之类的记录。

### popup 出现后怎么关闭

直接点击任何其他位置即可。popup 在失去焦点后会自动隐藏。

### 为什么有时会补发窗口全文

应用默认只发选区和截图给 AI。只有模型判断截图上下文不足时，才会补发窗口全文。

### 如何更换 Provider 或模型

直接修改控制面板中的 Base URL、文本模型、视觉模型，然后重新保存设置即可。
